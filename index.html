verifique packages

apt and dnf repositories for verifique, a verification queue for coding agents. They hold verifique @VERSION@, for x86-64 and ARM, signed with this key.

Debian and Ubuntu

curl -fsSL @URL@/verifique.gpg | sudo tee /usr/share/keyrings/verifique.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/verifique.gpg] @URL@/deb stable main" | sudo tee /etc/apt/sources.list.d/verifique.list
sudo apt update && sudo apt install verifique

Fedora and RHEL

sudo curl -fsSL -o /etc/yum.repos.d/verifique.repo @URL@/rpm/verifique.repo
sudo dnf install verifique

Arch Linux

From the AUR, with an AUR helper such as yay or paru:

yay -S verifique-bin

Upgrades then come with the rest of your system. Next, start the queue with verifique service install, as the README goes on to say. These packages are built from verifique's own releases by verifique-packages.
